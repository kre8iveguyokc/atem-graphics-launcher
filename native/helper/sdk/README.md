# Blackmagic ATEM Switchers SDK 11.0 (vendored subset)

Only the files needed to build agl-helper are included:

- mac/BMDSwitcherAPI.h, mac/BMDSwitcherAPIDispatch.cpp: from `Mac OS X/include`
- windows/BMDSwitcherAPI.idl: from `Windows/include`
- windows/BMDSwitcherAPI.h: MIDL output of that IDL as shipped by Blackmagic in `Windows/Samples/DeviceInfo`. Interface GUIDs checked against the IDL.

To update: replace these files from a newer SDK download and rebuild. The Mac dispatch symbol and Windows CLSID change between SDK versions, so the ATEM Switchers software installed on show laptops must be at least the SDK's version.

The SDK library itself is NOT included: it is installed with Blackmagic's ATEM Switchers software.
